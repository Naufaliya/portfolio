ARGUS — IoT Environment & Fire Monitor

ESP32-S3 IoT & C++ Web Dashboard

Overview

ARGUS adalah sistem pemantauan lingkungan dan deteksi kebakaran berbasis mikrokontroler ESP32-S3 yang dirancang untuk memantau kondisi ruangan secara real-time.

Key Features

  • Deteksi gas, asap, suhu, dan api secara real-time menggunakan integrasi multi-sensor.
  • Dashboard web bawaan untuk memantau pembacaan sensor dari jarak jauh.
  • Sistem daya cadangan (backup power) agar perangkat tetap aktif saat listrik padam.

Hardware & Architecture

Jelaskan alur kerja sistem, komponen sensor yang dipakai, atau tantangan saat kalibrasi dan integrasi perangkat keras di bagian ini.
