Computer Vision Dataset

CVAT Data Annotation Computer Vision

Overview

Pembuatan dan kurasi dataset gambar melalui proses pelabelan serta anotasi bounding box menggunakan CVAT (Computer Vision Annotation Tool) untuk melatih model Object Detection, khususnya deteksi atribut dan APD (PPE Detector).

Workflow & Key Activities

  • Ekstraksi frame dari rekaman video dan seleksi data visual untuk memastikan variasi sudut serta pencahayaan.
  • Pelabelan objek dan atribut secara presisi menggunakan bounding box di CVAT.
  • Pengecekan kualitas anotasi (quality control) sebelum tahap augmentasi data dan pelatihan model deteksi objek.

Impact

Dataset terstruktur yang dihasilkan menjadi fondasi utama dalam meningkatkan akurasi model AI dalam mengenali kelengkapan alat pelindung diri di lingkungan kerja.
